# 系统架构与方案：语义校验规则

规则集版本：0.1。状态：目标约束草案。日期：2026-10-12。

## 适用范围与评审输入

对应 PDR 对方案、组成、接口和集成准备的判断。依据[整体架构 0.2](../../../design/workflow_mbse_architecture.md)和[index](index.md)，同时应用[模型语义](../model_traceability/semantic_constrains.md)、[运行语义](../workflow_execution/semantic_constrains.md)。输入为固定需求、架构及方案/接口/集成材料、结构结果与未解决问题；workflow 配置的人或 AI AGENT 提供实际判断。规范文档不是判断记录。

允许比较充分性、指出缺口及返工范围；输出为架构适合性理由和 PDR 建议。

## 规则

| ID | 工程判据 | 评审证据 |
| --- | --- | --- |
| ARCH-SEM-001 | 选定方案能实现 Wish 与系统需求，约束、范围和非目标清楚；没有因复用既有工具而遗漏核心目标。 | Wish、需求、方案与范围 |
| ARCH-SEM-002 | 方案比较使用与项目相关的可行性、成本、复杂度和风险依据；选择理由解释取舍，单方案的依据足以排除不适用方向。 | 比较材料、约束与证据 |
| ARCH-SEM-003 | 部件责任、边界和依赖能够解释系统行为，每条分配有工程依据，关键状态和数据有明确负责模块。 | 项目模型、职责与需求覆盖 |
| ARCH-SEM-004 | 接口足以支持上下游协作，正常、失败、超时/取消及版本变化的责任明确；未确定字段可留到详细设计，但关键语义不能缺失。 | 接口与关键行为、失败场景 |
| ARCH-SEM-005 | 工作执行、结构检查、工程判断和运行推进的职责清楚，工具通过不能自行生成关卡批准；人/AI 和用户替代决定可沿同一协议交接。 | 模块交接、关卡及授权设计 |
| ARCH-SEM-006 | 原生模型、Wish 链、共享身份和 view 能支撑产品的核心查询，不以渲染缓存或文件清单替代工程模型。 | 查询场景、模型与 view |
| ARCH-SEM-007 | 信息归属、版本固定、源文件保存和记录提交在边界上可解释，冲突与部分完成可处理；历史选择能够恢复。 | 存储分工、采纳交接、恢复设计 |
| ARCH-SEM-008 | 运行方案覆盖显式返工、暂停重启、取消、重复请求与不确定外部效果；没有把合法 V-model 返工强制限制为无环执行。 | 运行场景、profile、状态责任 |
| ARCH-SEM-009 | 开发变更按选定依赖传播，能解释哪些决定重审/保留；用户规则显式演进不改旧发布，工具自举的候选机制不替换当前固定执行工具。 | 影响设计、规则与工具发布协议 |
| ARCH-SEM-010 | 集成计划检验真实架构主张，覆盖关键接口、失败交接和配置一致性；仅计划“所有模块跑通”不足以支持架构符合性。 | 集成用例、接口覆盖、判据 |
| ARCH-SEM-011 | 本地模块部署及复用 xdesign/Pilot 的边界符合当前目标，依赖能力与待建设能力有证据和风险说明；第一版之外的扩展没有成为无依据前提。 | 工具能力、接入设计、范围和风险 |
| ARCH-SEM-012 | 未解决问题及假设对详细设计的影响可接受；PDR 通过理由指出下游应展开的接口、状态、记录和验证责任，不提前声称 CDR/产品验收已完成。 | 问题处理、下一阶段准备、决定理由 |
| ARCH-SEM-013 | 固定工具与可变约束/工程内容的划分能支撑项目全生命周期：同一 T1 执行及读取各发布，规则调整不移动关卡；工具升级是独立迁移。 | 工具绑定、规则扩展、机制/内容边界 |
| ARCH-SEM-014 | 发布方案保证候选与评审同一选择、完整依赖、封存后不可变及只读继承；R1 后修改内容/规则/决定并发布 R2，R1 仍原样可读。共享内容和缓存策略不破坏这些性质。 | 发布方案、隔离验证计划、保留/损坏处理 |

## 出口与返工

逐项评估后形成 PDR 的 `pending/approved/rework/rejected` 建议，当前有效决定限定到 `detailedDesign`。若需求冲突使方案无法选定，返回系统需求；若责任、关键接口或集成准备不足，架构阶段返工。范围内例外依据公共协议保留，并传递给详细设计。

## 判定示例

充分：协调器负责推进与尝试，检查器提供事实，AGENT 提交有范围的决定，存储负责历史；架构解释用户修改后如何重算受影响阶段，并计划验证这个交接。

不足：语法上已有职责模块，却没有负责审查包固定、发布封存或只读访问的设计；或模板/实现硬编码关卡仅允许人判断。具体 workflow 选择所有关卡均由人判断属于允许配置。
