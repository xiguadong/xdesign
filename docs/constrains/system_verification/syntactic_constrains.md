# 系统验证阶段的语法与结构约束

规则集版本：0.1。日期：2026-10-12。状态：目标约束。

适用架构：[整体架构 0.2](../../../design/workflow_mbse_architecture.md)。项目初始化绑定工具发布 `T1` 及固定依赖：V-model、公共元模型、编译/解析、渲染和追溯机制在项目生命周期内保持不变，工具升级另行迁移。用户语法/阶段约束 SysML、语义评审约束 SysML、文档规范及外部规则可以发布新版本，新尝试显式采用；既有证据和决定保留原选择。

## 适用范围及依据

本规则用于 `systemVerification` 阶段的系统验证模型、需求覆盖、执行证据及审查包；关卡是 `System verification review`，下一工作为 `stakeholderValidation`（使用确认与验收）。系统验证的对象是系统需求符合性。机械检查通过不等于该关卡通过，更不能直接作为验收或 wish 完成结论。本规则是目标约束，不宣称检查器已经实现。

依据：[整体架构设计](../../../design/workflow_mbse_architecture.md)（0.2）的“固定工具与项目环境”“用户约束如何演进”“一次发布的执行过程”，[V-model 定义](../../../v_model_agents.sysml)的 `SystemVerificationAgentBehavior`、`systemVerifiesRequirements` 与 `System verification review`，以及 [Wish 生命周期模型](../../../wish_to_product.sysml)的 `SystemVerificationSpec`、`SystemVerificationBundle`、`Evidence` 和 `ContractedVModelDevelopment::systemVerification`。

通用要求见[路由说明](../README.md)、[模型与追溯语法约束](../model_traceability/syntactic_constrains.md)、[工作流执行语法约束](../workflow_execution/syntactic_constrains.md)；工程判断见[本阶段语义约束](semantic_constrains.md)。

## 输入、允许工作与产出

本阶段的模型、材料、实际证据、检查及新决定写入开发区持久资产/记录；从已发布成果继承时只读选定内容。用户修改结果新增开发决定，旧发布内的内容、原规则选择、决定及证据不变。提交发布时再按[项目发布语法约束](../project_release/syntactic_constrains.md)选择依赖并创建新的不可变发布，本阶段关卡不替代发布操作。

输入包含 wish/增量/尝试范围、当前集成验证基线及实际系统配置、选定系统需求基线与系统验证计划，以及流程、定义库、规则和依赖版本。集成验证基线是顺序输入，系统需求及其计划是验证依据；两者分别记录。

允许执行需求规定的测试、分析、检查或演示，登记实际环境及结果，更新验证模型、需求覆盖和 wish view，分析异常与变更影响。系统需求或系统实现需要修改时，形成变更及受控返工；不得为已有结果直接改写选定需求判据。

必须提交系统验证用例模型及适用的原生 `verify` 关系、实际系统与环境配置、逐需求/用例执行记录及原始证据、系统验证报告、覆盖/缺口和问题处置、版本清单、结构检查及 `System verification review` 审查包。现有模型缺少的状态、环境和历史字段使用阶段契约选定的结构化附属记录或明确类型的模型扩展。

## 出口与返工

结构不符合返回可定位诊断。合规审查包交由 workflow 配置的人或 AI AGENT 判断系统需求是否获得足够证据；协调器结合当前有效 `System verification review` 决定、契约和运行前提安排使用确认与验收。

发现需求、架构、实现、集成或方法问题，按影响评估返回流程声明的相应阶段并建立新尝试。结果不确定先核对观察及外部效果，再决定复验。系统验证出口只提供系统需求符合性及其限制，使用确认与验收仍需自己的证据及决定。

## 例子

合格：需求 `REQ-17@2` 规定告警时延上限，用例引用该需求与判据，在系统 `SYS-31` 和选定负载下记录输入时间、告警时间及测量精度。一次超限失败保留，修订后运行有独立身份及复验引用；覆盖表标出另一条未执行需求，审查包保持该缺口而不宣称全部通过。

不合格：系统解析成功且存在 `verify` 关系，就写 `Evidence.passed=true`；报告未标系统构建，执行工具断线仍计为通过，关卡申请下一步直接“产品验收完成”。违反 SV-SYN-003、005、006、010。
